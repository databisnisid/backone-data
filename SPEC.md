# SPEC.md — BackOne Data

## §G — Goal

Rework BackOne Data into full decoupled app: Next.js frontend (React 19, App Router) re-skins ALL user screens per the "Mockup Sites Dashboard" mockup; Django 5.2 DRF backend serves JSON + files; hourly `sync_data` feeds upstream-synced sites (read-only). Wagtail retired to superuser-only console at `/django-admin/`. The `/sites` grid spans every status by default — dismantled sites are no longer hidden, and are marked with a textual `Dismantled` badge. The dashboard carries an SDWAN package pie beside the provider panel, splitting the viewer's active sites by package, and each slice links into the grid filtered to that package. A link's provider is now a lookup-table value (`LinkProvider`, seeded `TELKOM`/`ICON`) edited on the same `/settings/lookups` page as SDWAN/BAA/role, so it is picked not typed; the `/sites` provider filter still offers only the providers the caller's own sites actually carry. Both the dashboard and the `/sites` grid are now narrowable to one or more network groups: the dashboard header carries a multi-select that re-scopes every card without changing what any card counts, and the grid gains a matching multi-select whose options come from the caller's own sites, with ungrouped sites reachable through a `Tanpa Group` sentinel.
